# Entra ID Log Analyzer Beta

A client-side tool for analyzing Azure AD / Entra ID authentication and audit logs.  
Upload JSON logs, visualize sign-in patterns, detect anomalies, and simulate attack scenarios.

## Features

- Upload or paste Entra ID/Azure AD logs (JSON)
- Interactive charts: sign-in status, timeline, privileged actions
- Deviation analysis: IP, time, app, geo, device
- Advanced correlation: multi-vector threats, impossible travel, behavioral clusters
- Risk analysis and DFIR patterns
- Sample logs and scripts for research/offensive simulation

## Usage

1. Open [`index.html`](index.html) in your browser.
2. Upload or paste your log file.
3. Review analysis, charts, and risk findings.
