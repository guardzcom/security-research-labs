# Research

**Structured research outputs, landscape studies, and reference materials** produced by the Security Research Labs team. This folder holds artifacts that support detection engineering, threat intelligence, and defensive research—not executable tools (those live in the repo root categories).

## Purpose

- **Landscape studies** — Surveys of attack tools, TTPs, or vendor ecosystems (e.g., AiTM tooling).
- **Reference datasets** — Curated lists, taxonomies, or mappings used for detection or triage.
- **Research notes** — Organized findings that may later feed into tools, detections, or public reports.

Use only in line with the repo’s [security model](../README.md#security-model-important) and authorized-use policy.

## Folder layout

| Folder | Description |
|--------|-------------|
| [M365/](M365/) | Microsoft 365 / Entra–related research: AiTM attack tools landscape, token-theft and phishing tooling, and M365-specific threat research. |

## Contributing

Add new research under a topic folder (e.g. `M365`, `Endpoint`, `ThreatIntel`). Each topic folder should have its own README describing contents and how to use or cite them.
