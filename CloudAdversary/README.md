# CloudAdversary

**Goal:** Cloud adversary and red-team tooling for authorized testing of Microsoft 365, Entra ID, and related services. Scripts support reconnaissance, device-code flows, SharePoint/OneDrive recon, Entra ID Smart Lockout validation, and GraphRunner-based operations.

**Authorized use only.** Use only on tenants and assets you own or have explicit permission to test.
